**Honest integrity note (NOT faked):** passage count, source breakdown, and split
assignment **exactly match** the manifest; leakage and secrets are clean; but
the byte-level SHA-256 of the locally-staged `01_normalized.jsonl` differs from
the manifest's recorded hash. The staged file is a **re-staged copy** (its
content/counts match but bytes differ from the version the manifest recorded
during the prior Kaggle run). The validator surfaces this as a hard `sha256
mismatch` error and sets `content_ready=True` with an `integrity_note` — it does
**not** rewrite the manifest hash to force a match.

Leakage-check design note: the check matches **full benchmark prompts** (e.g.
`"What is the Red Planet?"`), never bare concepts. Bare concepts like "Red
Planet" / "Newton's second law of motion" appear as ordinary encyclopedia
prose in the wikipedia passages and were correctly excluded after an initial
run false-positive-flagged them.
