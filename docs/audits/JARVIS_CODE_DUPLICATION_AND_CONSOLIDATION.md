## Inventory method and limits

- Tracked basename groups were counted using `git ls-files`; repeated names were
  reviewed for responsibility, not treated as automatic duplicates.
- Source imports, route assembly, and selected UI call sites were searched in
  this checkout. Dynamic plugin loading, all reflection, and every external
  deployment consumer were not exhaustively proven.
- The backend imports `research_engine` from `jarvis_backend` modules, but no
  `research_engine` package is tracked in this repository. In the current
  machine, Python resolves it from the parent `F:\AI` workspace. This checkout
  must not silently rely on that unrelated mutable source; make the package an
  explicit versioned dependency or obtain authorization to migrate its
  implementation before claiming a standalone backend.
- No candidate above was deleted as part of this audit. Consolidation that can
  alter persisted data, API contracts, route availability, or external launch
  behavior remains blocked until consumer and migration evidence is complete.
